# LangChain4j + Ollama Starter

Java 21 Maven starter project for IntelliJ IDEA.

1. Extract the ZIP.
2. In IntelliJ IDEA, choose **Open** and select the extracted `lc4j-ollama-starter` folder (or `pom.xml`).
3. Select JDK 21 and reload Maven dependencies.
4. Install Ollama separately and pull a model when ready for the lesson.
5. Add demo code to `src/main/java/com/telusko/Main.java` during recording.

No demo implementation is included.
