# LangChain4j Response Metadata & Token Usage — Starter

Java 21 / Maven / LangChain4j 1.18.1 / OpenAI

Open pom.xml as a Maven project in IntelliJ IDEA, select JDK 21, and reload Maven dependencies.

Set OPENAI_API_KEY in your IntelliJ run configuration when you add the LLM demo.

Main.java intentionally contains no implementation. Add ChatResponse, token usage, finish reason, response metadata, and cost-estimation examples while recording.

Teaching notes: Usage fields may be unavailable for some responses/providers. Price is an estimate and depends on the selected model, current pricing, caching, and other billing categories.
