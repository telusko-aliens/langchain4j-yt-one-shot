# Multi-Agent Demo — IntelliJ IDEA Starter

Java 21 + Maven + LangChain4j OpenAI and Agentic dependencies.

1. Extract ZIP.
2. IntelliJ IDEA > Open > select `multi-agent-demo` folder (or `pom.xml`).
3. Select JDK 21 and reload Maven dependencies.
4. Add agent implementation live during recording.
5. Set `OPENAI_API_KEY` in your IntelliJ run configuration when ready to call OpenAI.

Starter contains no agent logic.
